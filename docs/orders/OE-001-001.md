## Critérios de aceite cobertos
1. Sem `DATABASE_URL`, a apresentação continua disponível e `/api/ready` retorna 503.
2. Com adaptador saudável, `/api/ready` retorna 200.
3. URL de API desconhecida responde JSON 404.
4. Payload excessivo responde 413.
5. Erro interno não devolve string de conexão ou stack ao cliente.
6. Respostas trazem `requestId` válido para correlação operacional.
7. UI possui loading, erro/recuperação e sucesso de apresentação.
8. Layout se adapta a desktop, tablet e mobile, com foco visível e reduced motion.
9. Neon de homologação respondeu a consulta real e contém a migration 0001 aplicada.
