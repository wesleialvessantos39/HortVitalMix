# OE-001-001 — Estrutura

## Fonte normativa
`HortiVitalMix_Manual_Mestre_Tecnico_Greenfield_v6.pdf`, Módulo 001, OE-001-001.

## Entrega
- Frontend React/TypeScript com página pública responsiva e estado real de indisponibilidade.
- API Express modular com rotas, serviço e repositório PostgreSQL separados.
- `requestId` centralizado e devolvido em todas as respostas de API.
- Tratamento centralizado para 404 JSON, JSON inválido, payload acima de 256 KiB e erro interno sem vazamento de conexão.
- Readiness 503 sem banco e 200 apenas quando o PostgreSQL responde.
- Pool PostgreSQL real com encerramento gracioso em `SIGTERM`/`SIGINT`.
- Contratos TypeScript + validação de runtime com Zod.
- Migration `0001_oe_001_001_foundation.sql` para histórico de migrations.
- Vercel preparado com build Vite e função Express em `api/index.ts`.
- CI com typecheck, testes e build.

## Endpoints
- `GET /api/health`
- `GET /api/ready`
- `GET /api/v1/config`
- `GET /api/v1/environment`

## Critérios de aceite cobertos
1. Sem `DATABASE_URL`, a apresentação pode abrir; `/api/ready` responde 503.
2. Com adaptador saudável, `/api/ready` responde 200.
3. URL de API desconhecida responde JSON 404.
4. Payload excessivo responde 413.
5. Erro interno não devolve string de conexão ou stack ao cliente.
6. Respostas trazem `requestId` para correlação operacional.
7. UI possui estados de carregamento, erro/recuperação e sucesso de apresentação.
8. Layout se adapta a desktop, tablet e mobile, com foco visível e reduced motion.
